### 🚀 Demonstração & Tecnologias
Este projeto foi desenvolvido utilizando as melhores práticas do ecossistema front-end moderno:
- **HTML5 Semântico:** Estrutura limpa e acessível.
- **Tailwind CSS (v4):** Estilização utilitária (*utility-first*), responsividade e design em modo escuro (*Dark Mode*).
- **JavaScript (ES6+):** Lógica assíncrona (`async/await`, `fetch`), manipulação de DOM e persistência local (`localStorage`).
- **Consumo de API:** Integração com serviços de clima para obtenção de dados dinâmicos.

---

### ✨ Funcionalidades
- **Busca por Cidade:** Digite o nome de qualquer cidade para consultar instantaneamente as condições climáticas.
- **Métricas Detalhadas:** Exibição de temperatura atual, sensação térmica, umidade relativa do ar, velocidade do vento e pressão atmosférica.
- **Persistência de Última Consulta:** O sistema lembra da última cidade pesquisada utilizando o `localStorage` do navegador.
- **Design Responsivo:** Adaptado perfeitamente para dispositivos móveis e computadores.
